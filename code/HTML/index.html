❀ Instructions

Input

Determine the total circumference around the arm hole by measuring the length of the armscyes and adding them together. Fill in that total circumference in the input box.

Choose a seam location. The seam location determines whether the curve goes up and then down (under) or up, down, then up again (back).

Output

The sleeve cap width and height will be displayed after the calculation. If you feel confident that you can draw the curve yourself, you can use these dimensions and skip the next step!

Function

Draw the points from the table on grid paper and connect the dots. Then cut along the curve.
The function is symmetric in multiple ways so only drawing half, or even only a quarter, of the curve should be enough to construct the whole curve.
